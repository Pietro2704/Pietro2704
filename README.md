## 🏢 Trace Analysis

Sou fundador da **[Trace Analysis](https://traceanalysis.com.br)**, uma plataforma **SaaS voltada à área da saúde** que integra um espectrofotômetro a uma aplicação web para medir minerais, elementos-traço e metais tóxicos em tecidos vivos, de forma não invasiva.

No projeto, atuo em toda a stack: comunicação com hardware, processamento e armazenamento de dados, autenticação, APIs e geração de relatórios em PDF com gráficos analíticos para apoiar decisões clínicas.
